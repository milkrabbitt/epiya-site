网站如何运行

本网站由杭州壹湃科技有限公司运营，使用 GitHub Pages 托管静态页面。网站不提供账号注册、付款、联系表单，也未接入广告或访问统计脚本。我们不在网站代码中设置用于追踪访客的 Cookie。

托管服务处理的信息

访问网站时，GitHub 作为托管服务提供方可能处理请求所需的技术信息，包括 IP 地址和访问日志，以保障服务安全与运行。关于 GitHub 的处理方式，请参阅GitHub 隐私声明。本网站运营方没有通过此静态站点设置独立的访客行为统计。

通过邮件联系

点击本站的邮件链接会打开你自己的邮件应用。若你向 contact@epiya.cn 发送邮件，我们会为处理来信及回复而使用你主动提供的邮件地址和内容。请不要在普通邮件中发送密码、验证码或不必要的敏感资料。

产品隐私

喵喵键盘和 Relic 的具体数据处理取决于各产品实际功能。此处是公司网站说明，不替代各产品独立的隐私说明。
